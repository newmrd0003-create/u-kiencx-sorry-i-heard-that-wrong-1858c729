One line: the apology a smart speaker gives its owner after mishearing them. The program writes the line to `entry.txt`.

## Entry

> Sorry, I heard 'goodnight' as 'good knight' — a man in armour is at your door, and I've already knighted the cat.

## Why this angle

The field is flooded with "order more milk" → mother-in-law / cow, "tacos" → "toddlers", "turn it down" → "burn it down", and flights instead of dimming lights. This one takes a different road: a single misheard word ("goodnight" → "good knight") that escalates into a small medieval emergency — a man in armour at the door, and the cat already knighted. It sounds like something the speaker would actually say out loud, apologetic and a little too proud of the mess it made, and the punchline lands on the last three words.

## How to run

```sh
python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
